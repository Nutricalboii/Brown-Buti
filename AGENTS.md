# Design Review Rules (Apple HIG)

When reviewing or building UI/UX designs for Brown Buti, adhere to the cross-platform Apple Human Interface Guidelines (HIG) standards defined in:
- `.apple-design-skill/SKILL.md` — Main review methodology & severity scoring
- `.apple-design-skill/references/hig-lookup.md` — Topic routing & guidelines mapping
- `.apple-design-skill/references/hig/` — HIG design guideline documents (color, typography, layout, dark-mode, liquid-glass, accessibility, motion, etc.)

Always consult these guidelines before making layout, styling, or component updates.
